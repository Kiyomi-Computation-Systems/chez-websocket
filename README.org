** Status

The primitives are done (M1): SHA-1, base64 and a UTF-8 checker that takes a
text in pieces. So is the frame codec (M2): it reads a client's frames in
pieces of any size, refusing what no client may send, and builds the
server's. So is the protocol (M3): one connection's rules, as steps that read
no clock and do no I/O. It delivers whole messages, caps their size, checks
text as it comes, stops reading while its queue is full, closes as RFC 6455
asks, and pings a client gone quiet. So is the opening handshake's check
(M4.1): it answers a client's handshake with the 101's fields or a refusal,
and refuses a browser's page from another host unless the handler names it.
So is the binding (M4): a handler answers what =websocket-accept= returns, and
its code reads each message with a call that waits, sends, and closes. A client
that stops reading is cut off after a timeout, unless pinging is off or the
handler has stopped taking its messages. An idle connection costs the server
about 8 KB. Each part is held to its RFC's test vectors and examples, and the
binding on a real socket too.
[[https://github.com/crossbario/autobahn-testsuite][Autobahn|Testsuite]] holds it
to the RFC in CI (M5): an echo server built from it meets all 301 of its cases
without compression, and a ratchet holds each case's verdict. v0.1.0 (M6) is
next. No compression and no client. See [[file:.plans/2026-10-04-chez-websocket-project-brief.md][the project brief]],
[[file:.plans/2026-10-04-chez-websocket-design.md][the design]] and
[[file:.plans/2026-10-04-chez-websocket-milestone-plan.md][the milestone plan]].

** Building

You need Chez Scheme 10.4.1 or later, built with threads, and libuv 1.48 or
later, Ubuntu 24.04's. With none, or an older one such as Debian 12's 1.44,
chez-libuv builds its own, which needs CMake 3.10 or later. The one dependency,
chez-http-server, is a submodule pinned at a release tag, and it brings its own
pinned dependencies. All but chez-srfi are private.

#+begin_src sh
make submodules   # clone chez-http-server v0.5.0 and the pins it carries
make test         # build chez-libuv's shim, check every pin, run the suites
make autobahn     # Autobahn's 301 cases against an echo server, in Docker
make help         # every target
#+end_src

=make autobahn= needs Docker. Autobahn's image is built for amd64, so Docker
emulates it on other machines. On Linux the echo server runs on your machine.
On macOS and Windows, whose Docker Desktop has no host network, it runs in a
Linux container beside Autobahn: =make echo-image= builds it, the first time
in about four minutes, and =make docker-smoke= checks it starts and stops.
